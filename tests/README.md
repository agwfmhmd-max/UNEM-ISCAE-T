# الاختبارات

لا تؤثر على بناء الموقع (مجلد مستقل بـ package.json خاص به).

```bash
cd tests
npm install && npx playwright install chromium
npm test                       # كل اختبارات الواجهة (10 مجموعات)
PGURL=postgres://postgres@localhost/postgres npm test     # + اختبارات قاعدة البيانات
```

| المجموعة | ما تغطيه |
|---|---|
| `app-load` | تحميل الصفحة الرئيسية كاملة: كل سكربتات `/legacy` تُحمَّل، لا أخطاء جافاسكربت، أرقام `?v=` حديثة |
| `subjects` | فتح مادة: جلب الملفات من قاعدة البيانات + التخزين + GitHub، المواد المشتركة بدون تكرار (دوال `app.html` الحقيقية) |
| `community` | منشورات/تعليقات/رسائل: تعديل وحذف وتثبيت وتمديد، البحث برقم التسجيل والحد، المراسلة، التحديث اللحظي والاحتياط |
| `home` | عدّاد الزوار والمسجلين وتحكم المشرف، صورة الشارة، نافذتا التثبيت والإشعارات |
| `prompts-admin` | تحكّم المشرف بنافذتي التثبيت والإشعارات (إخفاء/إظهار/إعادة الإظهار) ومفاتيح لوحة الإعدادات |
| `prompts-guard` | الحارس داخل `app.html` (يمنع النافذتين حتى مع JS قديم) + كاشف عدم تطابق الملفات على الصفحة كاملة |
| `visual-baseline` | **حارس الأنماط:** بصمة الأنماط المحسوبة لـ app (جوال/حاسوب/داكن) وemplois وresultats والمجتمع مقابل `baselines/styles.json` — يلتقط تغيير CSS غير مقصود. للتغيير المقصود: `UPDATE_BASELINE=1` |
| `ops-tools` | أداة فحص الموقع الحي: سليم / ملف قديم / ملف مفقود / موقع متوقف |
| `gate-login` | تسجيل دخول الطالب: موجود، جديد (إنشاء ثم موافقة)، التحقق من المدخلات، جهاز مستعمل |
| `upload` | رفع الملفات: التحقق، التجهيز، طلب التوقيع، الرفع إلى Cloudinary، رسائل الأخطاء |
| `smart-classifier` | تصنيف الصور: MIME غير القياسي من Android/Samsung، إرسال الصورة إلى الرؤية، وإظهار أخطاء الخدمة |

الاختبارات تستعمل خادماً وهمياً، فلا تلمس قاعدة بياناتك الحقيقية ولا Cloudinary.
متغير `CHROME_PATH` اختياري لتحديد متصفح Chromium موجود مسبقاً.

**تلقائياً على GitHub:** `.github/workflows/ci.yml` يشغّل هذه الاختبارات (واختبارات القاعدة) عند كل رفع — انظر `README.md` في الجذر.

## اختبار حي لواجهة تصنيف الصور

هذا اختبار تكاملي يرسل صورة دراسية حقيقية إلى واجهة التصنيف، ويتحقق من HTTP والاستجابة والحقول وثقة التصنيف. يحتاج رمز جلسة Supabase صالحاً لحساب يملك دور `uploader` أو `admin`، ولا يُشغّل ضمن الاختبارات العامة لأن بيانات الدخول والصورة يجب أن يقدمهما المشغّل.

```bash
cd tests
CLASSIFIER_TOKEN='رمز_جلسة_Supabase' \
CLASSIFIER_IMAGE='/path/to/study-document.jpg' \
npm run test:classifier
```

يُستخدم رابط الإنتاج `https://unem-iscae2-test.vercel.app/api/public/upload/classify` افتراضياً. يمكن اختبار نشر آخر عبر `CLASSIFIER_API_URL`. الصيغ المقبولة JPG وPNG وWebP، والحد الأقصى 6 MiB. لا تُدرج رمز الجلسة في الأوامر المحفوظة أو السجلات؛ استخدم متغير بيئة آمن.
