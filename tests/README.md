# الاختبارات

لا تؤثر على بناء الموقع (مجلد مستقل بـ package.json خاص به).

```bash
cd tests
npm install && npx playwright install chromium
npm test                       # كل اختبارات الواجهة (6 مجموعات)
PGURL=postgres://postgres@localhost/postgres npm test     # + اختبارات قاعدة البيانات
```

| المجموعة | ما تغطيه |
|---|---|
| `app-load` | تحميل الصفحة الرئيسية كاملة: كل سكربتات `/legacy` تُحمَّل، لا أخطاء جافاسكربت، أرقام `?v=` حديثة |
| `subjects` | فتح مادة: جلب الملفات من قاعدة البيانات + التخزين + GitHub، المواد المشتركة بدون تكرار (دوال `app.html` الحقيقية) |
| `community` | منشورات/تعليقات/رسائل: تعديل وحذف وتثبيت وتمديد، البحث برقم التسجيل والحد، المراسلة، التحديث اللحظي والاحتياط |
| `home` | عدّاد الزوار والمسجلين وتحكم المشرف، صورة الشارة، نافذتا التثبيت والإشعارات |
| `gate-login` | تسجيل دخول الطالب: موجود، جديد (إنشاء ثم موافقة)، التحقق من المدخلات، جهاز مستعمل |
| `upload` | رفع الملفات: التحقق، التجهيز، طلب التوقيع، الرفع إلى Cloudinary، رسائل الأخطاء |

الاختبارات تستعمل خادماً وهمياً، فلا تلمس قاعدة بياناتك الحقيقية ولا Cloudinary.
متغير `CHROME_PATH` اختياري لتحديد متصفح Chromium موجود مسبقاً.
