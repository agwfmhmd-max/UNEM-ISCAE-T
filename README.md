## هيكل الواجهة والتطوير (مهم)

- `src/legacy/app.html` صار صغيراً (HTML + CSS): كل سكربتاته الكبيرة (18 ملفاً) انتقلت **حرفياً** إلى `public/legacy/app/NN-*.js` وتُحمَّل بنفس الترتيب،
  فتبقى المتغيرات والدوال العامة كما كانت. الفائدة: تحميل أسرع وتخزين مؤقت في المتصفح، وتعديل أسهل (الملف الرئيسي `03-main.js`).
- **بعد أي تعديل في ملف داخل `public/legacy/`** شغّل مرة واحدة: `node tools/bump-legacy.mjs` — يحدّث رقم `?v=` ليأخذ المتصفح النسخة الجديدة (يوجد اختبار يفشل إن نسيته).
- قاعدة البيانات: انظر `db/README.md`. الاختبارات: انظر `tests/README.md`.
- الدردشة تستعمل **Supabase Realtime Broadcast** للتحديث اللحظي (مفعّل افتراضياً في كل مشروع Supabase)، وتعود تلقائياً للاستطلاع كل 4 ثوانٍ إن تعذّر.
